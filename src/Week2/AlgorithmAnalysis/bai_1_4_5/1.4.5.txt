a. N + 1
~ N (do 1 << N khi N -> inf)

b. 1 + 1/N
~ 1 (do 1/N -> 0)

c. (1 + 1/N)(1 + 2/N) = 1 + 3/N + 2/N^2
~ 1 (do các số hạng chứa N -> 0)

d. 2N^3 - 15N^2 + N
~ 2N^3 (giữ lại số hạng bậc cao nhất)

e. lg(2N) / lg N = (1 + lg N) / lg N = 1 + 1/lg N
~ 1 (do 1/lg N -> 0)

f. lg(N^2 + 1) / lg N ~ lg(N^2) / lg N = 2 lg N / lg N
~ 2

g. N^100 / 2^N
-> 0 (do hàm mũ 2^N tăng nhanh hơn đa thức N^100)
