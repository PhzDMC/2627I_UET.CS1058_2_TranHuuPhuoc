- Phân tích lỗi:
    + Khi biến chạy i duyệt đến đúng vị trí p, giá trị leader[p] bị ghi đè thành leader[q]
    => Kể từ các vòng lặp sau (i>p) mọi phần tử đứng sau p cùng tập hợp với p
       sẽ bị bỏ qua, không được đổi sang gốc mới
- Testcase mà cài đặt trên chạy sai:
    n = 3 => leader = [0,1,2];
    union(1,2) => leader = [0,2,2]
    union(1,0) => leader = [0,0,2]
    Cặp (i=1,j=2) cùng nhóm nhưng find(1) = 0 != find(2) = 2 => kết quả sai
- Code khắc phục:
public void union(int p, int q) {
    int pid = leader[p];
    int qid = leader[q];
    if (pid == qid) return;
    for (int i = 0; i < leader.length; i++) {
        if (leader[i] == pid) {
            leader[i] = qid;
        }
    }
}
